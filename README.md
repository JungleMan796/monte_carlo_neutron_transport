# monte_carlo_neutron_transport
Monte Carlo simulation of neutron transport in Python, utilising stochastic sampling, three-dimensional random walks and statistical analysis to model neutron behaviour through different materials, with a particular emphasis on computational efficiency and uncertainty quantification.

Project 3 of the module PHYS20762 Computational Physics (Year 2, Semester 4, 2025). This project has been committed to GitHub much later.
